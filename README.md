# ועד הורים גן שלנו 🏫

אתר לניהול תקציב, גבייה והוצאות של ועד הורים בגן ילדים.
ממשק בעברית (RTL), עיצוב פסטל צבעוני, מותאם לנייד ולמסך רחב.

![ללא תלויות](https://img.shields.io/badge/dependencies-none-5D9E72)

---

## הפעלה

האתר בנוי מ־HTML, CSS ו־JavaScript בלבד — בלי שלב בנייה ובלי התקנות.

**הכי פשוט:** לפתוח את `index.html` בדפדפן (לחיצה כפולה על הקובץ).

**או דרך שרת מקומי** (מומלץ לפיתוח):

```bash
npx http-server -p 8080 .
# ואז לפתוח http://localhost:8080
```

בכניסה הראשונה אפשר ללחוץ על **"הצגת נתוני דוגמה"** כדי לראות את המערכת מלאה בנתונים לדוגמה.

## מה יש באתר

### אשף הקמה (4 שלבים — אפשר לדלג על כל אחד)

1. **פרטי הגן** — שם, כתובת, שנת לימודים ואיש קשר
2. **ילדי הגן** — שמות, ימי הולדת ופרטי ההורים
3. **צוות הגן** — שמות, תפקידים והיררכיה (אופציונלי)
4. **תכנון תקציב** — סעיפי ההוצאה המתוכננים

### לשונית תכנון תקציב 🧮

- כמות הילדים בגן (ניתן לעדכון בכל שלב)
- כמות הצוות וההיררכיה שלו — גננת, סייעת, מטפלת, מורה לחוג
- הוספת שורות סעיפי הוצאה מתוך קטגוריות, עם סכום ותאריך יעד
  (למתי צריך להביא את המתנה)
- קטגוריות ברירת מחדל: מתנה ליום הולדת, מתנה לחג לילדים ולצוות,
  מתנת סוף שנה, חוגים במימון אישי, כיבוד, פעילויות, ציוד, אחר —
  וניתן להוסיף קטגוריות משלכם
- תצוגת הסכום הכולל של כל הקטגוריות ופילוח גרפי

### לשונית גבייה 💰

- כמה כל הורה שילם, באיזה אמצעי — מזומן, פייבוקס, ביט, העברה בנקאית, צ׳ק
- כמה נשאר לשלם, וסטטוס לכל הורה (שולם / חלקי / טרם שולם)
- פריסה לתשלומים עם חישוב אוטומטי של הסכום לכל תשלום
- **ילד שמצטרף באמצע שנה** מקבל אוטומטית אחוז השתתפות מופחת
  לפי תאריך ההצטרפות (וניתן גם לקבוע אחוז ידנית)
- שליחת תזכורת תשלום להורה בוואטסאפ

### לשונית הוצאות 🧾

- ההוצאות בפועל מול התקציב המתוכנן, לכל קטגוריה ובסך הכל
- חישוב היתרה בתקציב ובקופה, והתראה על חריגה

### עמוד סוף שנה 🎈

חישוב כמה להחזיר לכל הורה:

1. סוכמים את ההוצאות בפועל
2. מחלקים אותן ביחידות ההשתתפות (ילד מלא = 1, ילד שהצטרף באמצע שנה = החלק היחסי)
3. לכל הורה מחשבים את חלקו האמיתי בהוצאות ומחסרים ממה ששילם
4. מי ששילם יותר מחלקו מקבל החזר, מי ששילם פחות משלים את ההפרש

כך ילד שהצטרף באמצע שנה משלם ומקבל בחזרה רק לפי אחוז ההשתתפות שלו.

### לשונית פרטי הילדים 🧒

ימי הולדת, שמות ההורים וטלפונים — עם חיוג ישיר ושליחת וואטסאפ.

### לשונית רעיונות למתנות 💡 (סיעור מוחות)

עמוד המחולק לריבועים בכמות בלתי מוגבלת. בכל ריבוע:

- בחירת קטגוריית תקציב מתוך סעיפי ההוצאה שהוגדרו
- בחירת קהל יעד: ילדים / צוות / כיבוד
- שורות של סעיף הוצאה וסכום, עם כפתור להוספת שורות
- תצוגת הסכום הכולל של שורות ההוצאה
- **חלוקת התקציב** בין כל אנשי הצוות / ילדי הגן — כמה יוצא לכל אחד,
  וכמה זה עולה לכל הורה
- בדיקה מיידית אם הרעיון נכנס בתקציב שנותר בקטגוריה
- טבלת השוואה מהירה בין כל הרעיונות

בסוף בוחרים אחת האפשרויות — היא נכנסת ללשונית ההוצאות בפועל
והעלות יורדת מהתקציב.

**שליחה בוואטסאפ להתייעצות** — רשימת ההוצאות של הרעיון נשלחת להורים
כהודעה מעוצבת.

### לשונית תאריכים 📅

לוח שנה חודשי, ימי הולדת של הילדים והצוות, תאריכי היעד של סעיפי התקציב
ואירועי הגן.

## מבנה הקוד

```
index.html              — שלד העמוד וטעינת הסקריפטים
assets/styles.css       — מערכת העיצוב (פלטת פסטל, רכיבים, RTL, מסך רחב)
js/store.js             — מבנה הנתונים, שמירה ב-localStorage, נתוני דוגמה
js/calc.js              — מנוע החישובים: תקציב, אחוזי השתתפות, גבייה, החזרים
js/ui.js                — עזרי תצוגה: פורמט כספי ותאריכים, מודאלים, טפסים
js/app.js               — ניתוב בין המסכים וטיפול באירועים
js/views/               — המסכים:
  onboarding.js           אשף ההקמה
  home.js                 מסך הבית
  budget.js               תכנון תקציב
  collection.js           גבייה מההורים
  expenses.js             הוצאות בפועל
  children.js             ילדי הגן
  staff.js                צוות הגן
  dates.js                תאריכים ולוח שנה
  ideas.js                רעיונות למתנות
  yearend.js              חישוב החזרים לסוף שנה
  settings.js             הגדרות, גיבוי ואיפוס
```

## הנתונים שלכם

כל הנתונים נשמרים **במכשיר שלכם בלבד** (`localStorage` של הדפדפן)
ולא נשלחים לשום שרת. אין הרשמה ואין סיסמה.

מכיוון שכך:

- הנתונים לא מסונכרנים בין מכשירים או דפדפנים
- ניקוי נתוני הגלישה ימחק אותם
- מומלץ לייצא גיבוי מדי פעם דרך **הגדרות ⚙️ → ייצוא גיבוי**,
  ולטעון אותו בחזרה בעת הצורך
